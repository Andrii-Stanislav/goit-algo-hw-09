# Аналіз ефективності алгоритмів для видачі решти

## Опис алгоритмів

### 1. Жадібний алгоритм (Greedy)

- **Складність**: O(n), де n - кількість доступних номіналів монет
- **Просторова складність**: O(1)
- **Переваги**:
  - Простий у реалізації
  - Швидкий для малих сум
  - Не потребує додаткової пам'яті
- **Недоліки**:
  - Не завжди дає оптимальне рішення
  - Працює коректно тільки для певних наборів номіналів монет

### 2. Алгоритм динамічного програмування (Dynamic Programming)

- **Складність**: O(m \* n), де m - сума для видачі решти, n - кількість доступних номіналів монет
- **Просторова складність**: O(m)
- **Переваги**:
  - Завжди знаходить оптимальне рішення
  - Гарантує мінімальну кількість монет
- **Недоліки**:
  - Вимагає більше пам'яті
  - Повільніший для малих сум

## Висновки щодо ефективності

1. **Для малих сум** (до 100-200):

   - Жадібний алгоритм працює швидше
   - Різниця в часі виконання незначна
   - Жадібний алгоритм використовує менше пам'яті

2. **Для великих сум** (понад 200):

   - Алгоритм динамічного програмування стає більш ефективним
   - Забезпечує оптимальне рішення
   - Хоча використовує більше пам'яті, але гарантує мінімальну кількість монет

3. **Загальні рекомендації**:
   - Для реальних систем видачі решти краще використовувати алгоритм динамічного програмування
   - Він забезпечує оптимальність рішення незалежно від суми
   - Додаткові витрати пам'яті компенсуються гарантованою оптимальністю рішення

## Приклад роботи алгоритмів

Для суми 113:

- Жадібний алгоритм: {50: 2, 10: 1, 2: 1, 1: 1} (5 монет)
- Динамічне програмування: {50: 2, 10: 1, 2: 1, 1: 1} (5 монет)

В даному випадку обидва алгоритми дають однаковий результат, але для інших сум та наборів монет результат може відрізнятися.
